🔌 Local server

The server reads the bundle files for you. Without it this page can only show the catalog; with it you can preview, export and replace assets.

1. Install the requirements (once)

python -m pip install -r requirements.txt

2. Start it

python catalog_server.py AssetBundles

It opens http://127.0.0.1:7777 by itself. Use that page rather than this file on disk, and everything works with no extra setup.
